# Портфолио — статический сайт

Адаптивный сайт-портфолио на HTML, CSS и JavaScript. Не требует сборки и может размещаться на GitHub Pages.

## Перед публикацией

1. Откройте `index.html` и проверьте описание, проекты и навыки.
2. Замените ссылку `https://github.com/` на свой профиль GitHub.
3. Добавьте email или другие контакты, если хотите.
4. Уточните статус проектов: формулировки намеренно не выдают концепции и учебные проекты за коммерческий опыт.

## Публикация на GitHub Pages

1. Создайте на GitHub репозиторий с точным именем `ВАШ_USERNAME.github.io`.
2. Загрузите в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
5. Через несколько минут сайт будет доступен по адресу `https://ВАШ_USERNAME.github.io/`.

Если сайт не появляется сразу, подождите пару минут и проверьте вкладку **Actions** в репозитории.
